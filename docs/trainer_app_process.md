# สรุปกระบวนการใช้งานระบบ Trainer App (Safety Trainer Dashboard)

ระบบ **Trainer App** เป็นระบบสำหรับจัดการ ตารางงาน การตรวจประเมิน และบันทึกผลการปฏิบัติงานของทีม Safety ต่อหน้างานและพนักงานขับรถ (Drivers) 

## 👥 บทบาทผู้ใช้งาน (Roles)

ระบบถูกออกแบบมาให้รองรับการทำงานของ 2 บทบาทหลัก โดยมีการจำกัดสิทธิ (Role Lock) ที่ชัดเจนเพื่อป้องกันความผิดพลาด:

### 1. หัวหน้า Safety ขึ้นไป (Manager / Planner)
เป็นผู้บริหารจัดการแผนงานภาพรวม มีสิทธิในการมองเห็นและจัดการข้อมูลทั้งหมด:
- **สร้างและจ่ายงาน (Assign Task):** เป็นผู้กำหนดลงแผนงาน (Plan Date) ว่าให้เทรนเนอร์คนไหน รับผิดชอบไปดำเนินการที่แพลนท์ (Plant) และลูกค้า (Client) ใด
- **จัดการในปฏิทิน:** สามารถเพิ่ม ลบงาน หรือการ Drag & Drop เลื่อนวันตรวจงานในปฏิทิน (CalendarTask) ได้
- **ติดตามประสิทธิภาพ:** สามารถดูสถิติ "ประสิทธิภาพของเทรนเนอร์ (Trainer Performance)" แต่ละคนได้ เพื่อประเมินภาระงานและความสำเร็จของการเข้าตรวจ

### 2. เทรนเนอร์ (Safety Trainer)
เป็นผู้ปฏิบัติงาน จะถูกจำกัดสิทธิจากระบบ (Lock Role = `true`) ในบางการกระทำหลักๆ:
- **เข้าถึงงานของตนเอง:** ระบบจะแสดงงานทั้งหมด แต่เทรนเนอร์สามารถใช้ตัวกรองเพื่อดูงานของตนที่หัวหน้า Assign มาให้
- **ข้อจำกัดสิทธิ:** ไม่สามารถ "ลบงาน" ทิ้งได้เองโดยพลการ (สิทธิแก้ไขบางส่วนถูกล็อก)
- **การลงข้อมูลหน้างาน:** ต้องเข้าไปทำหน้าที่บันทึกข้อมูลการตรวจสอบสถานะคนขับและสภาพแวดล้อมที่ได้รับมอบหมาย

## 🔄 กระบวนการทำงาน (Workflow)

### Step 1: หัวหน้าวางแผนและ Assign งาน (Planning & Assignment)
1. หัวหน้า Safety เข้าสู่หน้าระบบ ระบบจะแสดงหน้าจอภาพรวมสรุป (Stat Cards)
2. หัวหน้าใช้ ฟังก์ชัน **Add Task** หรือจิ้มลงปฏิทิน เพื่อสร้างงาน (Inspection Task)
3. เลือก **ลูกค้า (Client)**, **สถานที่ตรวจ (Plant)**, **เทรนเนอร์ (Trainer)**, และ **วันที่ตามแผน (Plan Date)**
4. เมื่อสร้างเสร็จ งานจะมีสถานะเริ่มต้นเป็น **"เปิดงาน" (Open - สีฟ้า)**

### Step 2: เทรนเนอร์รับทราบและลงพื้นที่ (Execution)
1. เทรนเนอร์ล็อกอินเข้ามาในระบบ (ข้อมูลชื่อ ตำแหน่ง จะถูกเช็คจากการล็อกอิน)
2. เริ่มลงพื้นที่หน้างานตามวันและ Plan Date งานจะถูกมองว่าเป็น **"รอดำเนินการ" (Pending - สีเหลือง)**
3. คลิกเข้าไปที่งานนั้นๆ ระบบจะพาทะลุไปที่หน้าเข้าแบบฟอร์มตรวจสอบ (`/trainer-app/[id]`)

### Step 3: บันทึกผลการตรวจหน้างาน (Inspection Detail & Record)
ในหน้ารายละเอียดงาน เทรนเนอร์ต้องจัดการข้อมูล 3 ส่วนหลักๆ คือ:
1. **Safety Talk:** บันทึกหัวข้อ (Topics) ที่ได้อบรมหรือพูดคุยกับพนักงานขับรถ รวมถึงการลงบันทึกข้อความ (Noted)
2. **การตวจพนักงานขับรถ (Driver Table):**
   - จะมีรายชื่อพนักงานขับรถที่เกี่ยวโยงกับรอบงานนั้น
   - ตรวจสอบรายบุคคลในเรื่อง:
     - **PPE (อุปกรณ์ความปลอดภัย)**
     - **การตรวจสารเสพติด (Drug Test)**
     - **สภาพรถเบื้องต้น (Vehicle Inspect)**
3. **การส่งหลักฐานภาพถ่าย:** มีส่วนสำหรับอัปโหลดภาพ (Upload Slots) หลักฐานการตรวจลงระบบ 

### Step 4: อัปเดตสถานะและปิดงาน (Completion)
1. เมื่อดำเนินการตรวจพนักงานและลงข้อมูลเรียบร้อยทั้งหมด
2. สถานะของงานและการประเมินทั้งหมดจะรวบยอด และงานนั้นจะถูกปรับสถานะให้เป็น **"เสร็จสิ้น" (Completed / inspection_done - สีเขียว)**
3. หากมีเหตุให้ไม่สามารถเข้าไปได้ อาจมีการปรับปรุงสถานะเป็น **"ยกเลิก" (Cancel - สีแดง)**
4. หัวหน้าจะสามารถเห็นตัวเลข Performance จำนวน Task ที่ Done หรือ Pending ของสัปดาห์/เดือนนั้น ในฝั่งรายงานภาพรวม (ฝั่งหน้าแรก)

## 📊 ฟีเจอร์หลักในหน้าจอ (Key UI Features)
*   **Quick Stats:** บอร์ดตัวเลขแบบ Real-time รวบรวมงานทั้งหมด/รอดำเนินการ/ยกเลิก/เสร็จสิ้น
*   **Calendar + Task List:** มีทั้งมุมมองปฏิทินเพื่อให้ง่ายต่อการดูตาราง และ List Table ค้นหาละเอียด
*   **Filter System:** ตัวกรองระดับสูง ทั้งรายปี, รายเดือน, ชื่อเทรนเนอร์, โลเคชัน
*   **การวิเคราะห์แนวโน้ม (Analytics view):** *(กำลังพัฒนา)* ในหน้า Tab วิเคราะห์ เพื่อดูข้อมูลระดับประเมินความเสี่ยงต่างๆ
